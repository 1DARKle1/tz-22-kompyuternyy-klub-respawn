## Что сделать в аккаунтах

1. Создать публичный репозиторий GitHub с именем `tz-22-kompyuternyy-klub-respawn`. В нём должно быть не меньше 10 коммитов. Первый коммит — этот исходный результат без ручных правок.
2. Импортировать репозиторий в Vercel. Framework Preset: Other. Корень — корень репозитория. Build Command пустой. Output Directory: `.` Сайт обновляется после push в `main`.
3. Адрес сайта уже стоит в `README.md`, в `docs/utm.csv` и в QR. Если Vercel выдаст другой адрес, замени его в `scripts/make_assets.py` в переменной `SITE` и запусти `python scripts/make_assets.py`.
4. Тег `G-16J5BT8KWH` стоит в `<head>` каждой страницы, включая 404. В кабинете ещё нужно зарегистрировать параметры и ключевые события, шаг 5.
5. В GA4 зарегистрировать параметры события: `button_name`, `page_section`, `zone`, `time_band`, `search_term`, `lead_type`, `messenger`. Ключевыми отметить только `generate_lead`, `contact_click`, `messenger_click`.
6. Создать таблицу «Respawn — Bookings». В Apps Script вставить `apps-script/Code.gs`, вписать ID таблицы, один раз выполнить `setupSheet`, опубликовать веб-приложение: выполнять от своего имени, доступ «Все». Адрес `/exec` вписать в `js/config.js`.
7. Выдать заказчику просмотр таблицы. Имена, телефоны и почта на дашборд DataLens не выводить.
8. Проверить каждое событие в DebugView расширением Google Analytics Debugger. Снимки сложить в `screens/ga4/` под именем события. Режим `debug_mode` в код не добавлялся, перед сдачей его быть не должно.
9. Опубликовать ссылки из реестра в четырёх соцсетях отдельными страницами клуба, не с личного профиля. Короткие ссылки для ВКонтакте и Telegram проверить: после перехода все метки остаются в адресе.
10. Собрать ManyChat «IG · Respawn Nov 2026 · Reaction Reel» на ключевые слова РЕАКЦИЯ и ТУРНИР. Кнопки ведут на строки U-02 и U-03.
11. Через 24–48 часов снять отчёты GA4 и заполнить `docs/report.md` только теми числами, которые видны в отчётах.

Полная ссылка в Google Таблице собирается формулой из столбцов меток, а не набирается руками. Черновик в `docs/utm.csv` — выгрузка тех же строк.
